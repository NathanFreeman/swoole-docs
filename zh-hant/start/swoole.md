# Swoole

`Swoole` 是一個使用 `C++` 語言編寫的、基於異步事件驅動和協程的並行網絡通信引擎，爲 `PHP` 提供[協程](/zh-hant/coroutine/coroutine.html)與高性能的網絡編程支持。

它提供了多種通信協議的網絡服務器和客戶端模塊，可以方便快速地實現：

- `TCP` / `UDP` 服務
- 高性能 `Web` 應用
- `WebSocket` 服務
- 物聯網、實時通訊
- 遊戲服務器
- 微服務

`Swoole` 讓 `PHP` 不再侷限於傳統的 `Web` 領域。
