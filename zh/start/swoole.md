# Swoole

`Swoole` 是一个使用 `C++` 语言编写的、基于异步事件驱动和协程的并行网络通信引擎，为 `PHP` 提供[协程](/zh/coroutine/coroutine.html)与高性能的网络编程支持。

它提供了多种通信协议的网络服务器和客户端模块，可以方便快速地实现：

- `TCP` / `UDP` 服务
- 高性能 `Web` 应用
- `WebSocket` 服务
- 物联网、实时通讯
- 游戏服务器
- 微服务

`Swoole` 让 `PHP` 不再局限于传统的 `Web` 领域。
