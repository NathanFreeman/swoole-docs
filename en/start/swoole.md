# Swoole

`Swoole` is a parallel network communication engine written in `C++`, based on asynchronous event-driven I/O and coroutines, providing [coroutine](/en/coroutine/coroutine.html) and high-performance network programming support for `PHP`.

It provides network server and client modules for a variety of communication protocols, making it easy and fast to build:

- `TCP` / `UDP` services
- High-performance `Web` applications
- `WebSocket` services
- IoT and real-time communication
- Game servers
- Microservices

`Swoole` frees `PHP` from being confined to the traditional `Web` domain.
